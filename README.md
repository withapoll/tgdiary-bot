# tgdiary-bot

Агент-оппонент над приватным Telegram-каналом-дневником. Каркас для двухнедельного теста из `notesai/04-тест-2-недели.md`.

Только stdlib — ни одной внешней зависимости. Python 3.9+.

---

## Что делает

- Ловит посты канала, голосовые транскрибирует.
- Ждёт **реакцию** на пост — это явный жест «поработай с этим». Без реакции молчит.
- Отвечает в **комментарии** к посту, не засоряя ленту.
- Ведёт лог для метрик теста.

**Словарь реакций** (настраивается в `config.json`):

| Эмодзи | Скилл | Что делает |
|---|---|---|
| 🤔 | `oppose` | Ищет слабое место, возражает по существу |
| 🔍 | `research` | Ставит ТЗ на ресёрч: что проверить и где |
| 📌 | `remember` | Фиксирует решение + условие пересмотра |
| 👀 | `recall` | Ищет в архиве, что ты писал раньше, и показывает противоречия |

**Команды** (в группе обсуждений или в личке боту): `/find <запрос>`, `/digest`, `/stats`.

## Установка

```bash
cd tgdiary-bot
cp config.example.json config.json
```

Заполнить в `config.json`:
- `bot_token` — от @BotFather
- `channel_id` — вида `-100...`
- `llm.api_key` и `stt.api_key`

Запуск:

```bash
python bot.py
```

Проверка логики без Telegram и без LLM:

```bash
python selftest.py
```

## Настройка Telegram (обязательно)

1. **Канал → Управление → Обсуждения** — привязать группу. Без этого **бот физически не сможет отвечать в комментарии**.
2. **Бот — админ канала.**
3. **Бот — админ группы обсуждений** (право отправлять сообщения).
4. Проверить: `/stats` должен показать `linked > 0` после первого поста.

### Важное ограничение Bot API

В каналах реакции **анонимные**. Боту приходит не `message_reaction`, а `message_reaction_count` — только счётчики, **без автора**, и, по документации, «*can be sent with delay up to a few minutes*».

Практические следствия:
- В приватном соло-канале это неважно: 🔍 с `total_count: 1` — это ты.
- **Ответ придёт с задержкой в пару минут.** Это не баг, а свойство API — и для нашего сценария скорее плюс: мгновенная реакция вернула бы проблему прерывания.
- Бот не получает реакции, поставленные ботами → зациклиться не может.

## Импорт старого архива

Без длинной истории «архивариус» не проверяется — противоречия видны на горизонте месяцев.

1. Telegram Desktop → канал → ⋮ → **Export chat history** → формат **JSON**, с медиа.
2. ```bash
   python import_export.py "путь/к/result.json" --transcribe
   ```

Флаг `--transcribe` расшифрует голосовые (стоит денег, см. смету). Без него они сохранятся как `voice_untranscribed`.

**Сразу проверь качество расшифровки** — это главный технический риск проекта.

## Защиты, встроенные в код

Правила из промпт-конституции продублированы на уровне кода, потому что промпт можно обойти:

| Правило | Где реализовано |
|---|---|
| Не лезть в личное | `agent.is_personal()` — пост с маркерами (выгорание, болезнь, ссора и т.д.) **вообще не отправляется в LLM** и не попадает в контекст других запросов |
| Не хвалить | `_postprocess()` вырезает похвалу и пишет `violation` в лог |
| Молчать, когда нечего сказать | `SILENCE` → ответ не отправляется |
| Кривой транскрипт | `UNCLEAR` → бот переспрашивает вместо выводов |
| Не срабатывать дважды | дифф счётчиков реакций в `state.json` |

Фильтр личного намеренно грубый: лучше лишний раз промолчать, чем отправить в чужое API запись про выгорание.

## Структура

```
bot.py              приём апдейтов, роутинг, отправка
agent.py            конституция, скиллы, вызовы LLM, фильтры
store.py            JSONL-архив, состояние, лог метрик
transcribe.py       голос → текст (multipart на stdlib)
import_export.py    импорт выгрузки Telegram Desktop
selftest.py         10 проверок без сети
data/               posts.jsonl, state.json, agent_log.jsonl, media/
```

## Провайдеры

**OpenAI-совместимый** (по умолчанию) — работает с OpenAI, DeepSeek, любым прокси: поменять `llm.base_url` и `llm.model`.

**GigaChat** — `"provider": "gigachat"` и `auth_key` (Basic-ключ из личного кабинета). Актуально для РФ: прямая оплата OpenAI и Anthropic из России недоступна.

По расчётам из `notesai/02-economics.md` весь двухнедельный тест стоит **менее $15**, основная статья — ресёрчи по 🔍.

## Метрики теста

`/stats` отдаёт: постов, голосовых, связанных с комментариями, ответов агента, случаев молчания.

Полный лог — `data/agent_log.jsonl`, по одной записи на событие (`answer`, `silence`, `unclear`, `violation`). Пороги успеха зафиксированы в спеке до старта — не пересматривай их по ходу.
